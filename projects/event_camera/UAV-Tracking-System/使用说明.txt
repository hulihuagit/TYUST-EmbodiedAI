================================================================================
  基于时间表面的高速运动目标（无人机）检测与追踪系统
  使用说明  V2.0
================================================================================

【文件清单】

  无人机追踪系统.exe          桌面应用程序（双击运行，无需安装 Python）
  data\                       数据集目录（需要自己准备）
    ├── Event\Frames\*.png   事件帧图像（3233 张，1280×720）
    ├── RGB\*.jpg             RGB 帧图像（3233 张，1280×720）
    └── coordinates.txt       地面真值坐标标注


================================================================================
  一、快速开始
================================================================================

1. 确认 data\ 目录结构完整（见上方文件清单）。

2. 双击"无人机追踪系统.exe"，等待 3-5 秒启动。

3. 左侧面板确认数据目录指向 data\，文件校验显示绿色 ✅。

4. 在"预设方案"下拉框中选择"单目标高精度"，点击"加载"。

5. 点击底部绿色的"▶ 开始处理"按钮。

6. 右侧实时显示处理进度和预览画面。

7. 处理完成后，点击"打开视频"查看结果，或点击"打开输出目录"。

   输出文件位置：桌面 drone_tracking_output\ 文件夹
   - tracking_dashboard.mp4            2×2 仪表盘视频
   - tracking_dashboard_tracking_only.mp4  纯跟踪视角视频





================================================================================
  二、参数调节指南
================================================================================

【时间表面参数】

  衰减常数 τ（默认 20ms）
    控制事件在时间表面上的"记忆"时长。
    - 减小 τ（10-15ms）：适合高速无人机，减少拖尾
    - 增大 τ（30-50ms）：适合慢速/悬停目标，保留更长运动历史
    有效记忆时间 ≈ -τ × ln(阈值)

【检测器参数】

  最小面积（默认 10 px²）
    候选目标的最小像素面积。越小能检测越远的无人机，但也容易把噪点当目标。
    远距离小目标建议 3-8，近距离大目标建议 15-30。

  最大面积（默认 300 px²）
    防止大块背景连通域被当成目标。缩小此值可过滤大面积虚检。

  光流阈值（默认 0.5）
    候选框内平均运动幅度低于此值的被认为是静止虚检。
    - 提高（0.8-1.0）：更严格，减少虚检，但可能漏掉悬停目标
    - 降低（0.2-0.3）：更宽松，增加检出，但虚检增多

  保留检测数（默认 1）
    每帧最多保留几个候选框。设为 1 即单目标模式。

  启用多尺度检测通道
    勾选时运行三路检测（原始 + TopHat + DoG），检测更全面但速度慢。
    取消勾选只运行原始表面检测，速度翻倍。

【跟踪器参数】

  IoU 匹配阈值（默认 0.1）
    检测框与跟踪框匹配的最低重叠比例。小目标容易漂移，建议设低（0.05-0.15）。

  最大丢失帧数（默认 8）
    连续多少帧没有关联检测后判定目标永久丢失。
    - 减小（3-5）：快速清理虚检
    - 增大（12-20）：容忍更长遮挡，适合短暂飞出画面的场景

  确认命中数（默认 5）
    新目标需连续命中多少帧后才确认输出。
    - 减小（2-3）：更快响应新出现的目标
    - 增大（8-10）：更严格，减少虚假新目标

【常见问题调优】

  现象                            优先调整
  ────────────────────────────────────────────
  画面中全是检测框                提高光流阈值、减小 top_k
  无人机在画面中但没有检测框      降低 min_area、增大 tau
  跟踪频繁中断                    增大 max_lost、降低 min_hits
  检测框跟踪到背景而非无人机      缩小 max_area、提高光流阈值
  处理速度太慢                    降低分辨率、减少帧数、关闭多尺度


================================================================================
  三、预设方案说明
================================================================================

系统内置三个预设方案，可通过下拉框加载：

  单目标高精度（推荐）
    tau=20ms, 面积 10-300, 光流 0.5, top_k=1, max_lost=8, min_hits=5
    适合单架无人机、背景较干净的场景。

  快速预览
    tau=15ms, 面积 5-500, 光流 0.3, top_k=2, max_lost=10, min_hits=3
    适合快速验证数据是否能跑通，门控较宽松。

  多目标宽松
    tau=25ms, 面积 5-800, 光流 0.2, top_k=5, max_lost=15, min_hits=3
    适合有多架无人机且背景较复杂的场景。

也可以自己调参后点击"保存"，存为自定义预设。


================================================================================
四、命令行模式
================================================================================

如果不使用 GUI，也可以通过命令行运行：

  cd D:\PythonProject3
  python main.py --mode real --frames 0 --resolution 640x360

  完整参数列表：
  python main.py --help

  常用示例：
  python main.py --mode real --frames 500 --resolution 640x360 --top-k 1 --min-area 10 --max-area 300 --flow-threshold 0.5 --tau-ms 20

  模拟模式测试：
  python main.py --mode sim --num-drones 2 --frames 500

 五、输出文件说明
================================================================================

  桌面 drone_tracking_output\ 文件夹：

  tracking_dashboard.mp4
    2×2 仪表盘视频，四个面板：
      左上 ─ 时间表面伪彩色图（红=最近 ON 事件，蓝=最近 OFF 事件）
      右上 ─ 原始灰度帧 + 速度矢量（黄色箭头）
      左下 ─ 检测结果（橙色框 + 十字准星）
      右下 ─ 跟踪结果（彩色框 + ID 标签 + 轨迹线，主要输出）

  tracking_dashboard_tracking_only.mp4
    纯跟踪视角，只包含右下角面板的内容。

  两个视频均为 MP4 格式（mp4v 编码），30fps。如果系统自带播放器无法打开，
  请使用 VLC 播放器。


================================================================================
六、常见问题
================================================================================

Q: 双击 exe 后没有反应？
A: 等待 5-10 秒。exe 体积较大（145MB），首次启动需要解压到临时目录。
   如果超过 30 秒仍无反应，检查杀毒软件是否拦截（Windows Defender 可能误报）。

Q: 提示"Event/Frames/ 目录不存在"？
A: 确认 data\Event\Frames\ 目录下有 .png 文件。
   在界面中点击"📁"按钮导航到正确的数据目录。

Q: 处理过程中界面卡顿？
A: 正常现象。处理管道在后台线程运行，UI 每 100 帧更新一次。
   如需更快响应，降低处理分辨率或帧数。

Q: 输出视频大小为 0 或无法播放？
A: 检查磁盘空间。确保输出目录有写入权限。尝试用 VLC 播放器打开。

Q: 跟踪效果不好，覆盖率很低？
A: 首先尝试加载"快速预览"预设，确认管道能跑通。
   然后逐一调整参数（参考第三节参数调节指南）。
   如果仍然不理想，考虑更换数据集或检查事件帧质量。

Q: 能否在 Linux / macOS 上运行？
A: exe 仅支持 Windows。Linux/macOS 需从源码运行：
   git clone ... && pip install -r requirements.txt && python app.py

Q: 如何获取技术支持？
A: 提交 GitHub Issue 或联系项目负责人。

 七、技术参考
================================================================================

  核心技术栈：
    事件相机（Event Camera）   微秒级异步视觉传感器
    时间表面（Time Surface）    S(x,y,t) = exp(-(t-T)/τ)，双极性指数衰减
    多尺度检测                  原始 + TopHat + DoG + NMS + 光流验证
    KCF 跟踪器                 三通道特征（灰度+梯度+LoG），频域相关滤波
    卡尔曼滤波                 6维状态 [x,y,w,h,vx,vy]，约瑟夫协方差更新
    匈牙利匹配                 全局最优二分图匹配（O(n³)）

  参考文献：
    [1] FRED: The Florence RGB-Event Drone Dataset, ACM MM 2025
    [2] HOTS: Hierarchy of Event-Based Time-Surfaces, IEEE TPAMI 2017
    [3] High-Speed Tracking with KCF, IEEE TPAMI 2015
