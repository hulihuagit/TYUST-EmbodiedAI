无人机追踪系统

UAV Tracking System Based on Event Camera

📂 源代码 Source Code 📥 下载程序 (145MB) 📥 下载数据 (428MB)

项目简介

一套基于事件相机+时间表面表示的高速运动小目标检测与追踪软件平台。

技术流程

输入异步事件流 → 时间表面转换 → 多尺度检测 → KCF+卡尔曼跟踪 → 视频输出

功能特点

  • 支持模拟数据与FRED真实数据双模式
  • 已封装为PySide6桌面应用
  • 可执行文件无需安装Python环境

使用说明

  1. 下载 UAV-Tracking-System.exe
  2. 下载 data.tar.gz 并解压（使用 7-Zip 或 tar 命令）
  3. 运行 exe 文件
  4. 在界面中选择解压后的 data 文件夹中的视频进行测试

系统要求

  • Windows 10/11
  • 无需安装 Python 环境（独立可执行文件）
